# RuleDrive 🚀

**RuleDrive** is a lightweight and efficient Python automation tool designed to take the manual work out of file management. By defining simple rules, you can automate the organization of your workspace in seconds.

## ✨ Key Features
* **Smart Renaming:** Bulk rename files using custom patterns or timestamps.
* **Rule-Based Sorting:** Automatically move files to specific directories based on extensions, keywords, or dates.
* **Safe Cleanup:** Delete redundant or temporary files automatically based on your criteria.
* **Python Powered:** Fast, cross-platform, and easy to customize.

## 🛠️ How it Works
The tool scans your target directories and applies a set of logic-based rules defined in a configuration file (like JSON or YAML), ensuring your folders stay clean without lifting a finger.

## 🚀 Quick Start
1. Clone the repo: `git clone https://github.com/username/RuleDrive.git`
2. Configure your rules in `rules.json`.
3. Run the script: `python main.py`
